# Glossary

| Term | Working definition |
|---|---|
| Active workout | The locally durable, editable in-progress session state, distinct from its source plan and final completed record. |
| Assisted exercise | An exercise whose recorded assistance reduces the effective body load; assistance is stored separately from external resistance. |
| Completed workout | A finalised session snapshot with performances, notes, completion state, provenance, and an auditable edit history. |
| Deterministic rule | A rule that returns the same result from the same versioned inputs without probabilistic inference. |
| Double progression | Progress repetitions within a target range before increasing load when programme-defined completion conditions are met. |
| Drop set | One parent working set followed by one or more reduced-load efforts with explicit ordering and relationship. |
| Estimated 1RM | A formula-derived comparison estimate from load and repetitions; not an instruction to attempt that load. |
| Flexible sequence | A programme order such as A → B → C that advances by completed/explicitly skipped sessions rather than calendar weekday. |
| Ghost workout | Optional comparison against a previous equivalent, personal-best, or planned session. |
| Local-first | Core reads and writes complete on device; network synchronisation is deferred and cannot block workout use. |
| Planned workout | A dated or sequenced occurrence created from a versioned workout template. |
| Programme | A user-owned training plan that groups versioned workout templates, scheduling, and progression intent. |
| Programme version | Immutable snapshot of programme structure used to preserve historical meaning after edits. |
| Recommendation | Optional, explainable proposal that never mutates training data until accepted. |
| RIR | Repetitions in reserve: the user’s estimate of how many good repetitions remained. |
| RPE | Rating of perceived exertion; the product stores the selected scale and does not infer medical readiness. |
| Short-workout mode | User-invoked adaptation that preserves higher-priority work and explicitly identifies removed or reduced work. |
| Stable identifier | Non-recycled identifier that remains constant across edits, export, migration, and future synchronisation. |
| Substitution | Replacement of an exercise for one occurrence or future plan, with reason, intent match, and user confirmation. |
| Superset | Two or more exercises grouped for alternating execution, preserving independent set performances and order. |
| Timed exercise | An exercise whose primary performance unit is duration, optionally with distance, load, or repetitions. |
| Unilateral set | A set that records side and may contain independent left/right values while remaining one planned set position. |
| Warm-up set | A preparatory set excluded from default working-volume and progression completion unless explicitly configured otherwise. |
| Working set | A programme-relevant set eligible for completion, volume, record, and progression rules according to its set type. |

Where community terminology differs, the UI should prefer clear labels and short explanations over insider shorthand.

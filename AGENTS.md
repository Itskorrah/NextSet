# NextSet project constitution

NextSet serves mainstream gym users with fast repeated logging, flexible programmes, explainable guidance, and reliable local workout data.

This repository is in the foundation phase. Do not begin production implementation until the product owner approves product scope, visual direction, architecture, and critical journeys.

Never commit credentials or private user data. Preserve accessibility, privacy, local data safety, user control, and reviewable Git history. Do not force-push or merge the foundation pull request without approval.
